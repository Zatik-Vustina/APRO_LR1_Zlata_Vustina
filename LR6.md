# Лабораторная работа №6. Telegram-оповещения

Задача `notify` ждёт окончания всех существующих задач пайплайна. На push в `main` основного репозитория она выполняется через `always()`, в том числе если `run_tests` остановилась на активации Unity и Docker был пропущен. При успехе указывается ссылка на игру, если настроена переменная репозитория `UNITY_GAME_URL` с фактическим HTTPS-адресом опубликованного WebGL.

## Проверка без Unity

На ветке `LR6` отдельный workflow **LR6 Telegram independent check** запускает тесты с HTTP-имитатором Telegram. Он проверяет полезную нагрузку для успеха и ошибки Unity, а также ответы с HTTP-ошибками, неверным JSON и `ok=false`. Локально те же тесты запускаются из корня проекта:

```powershell
python -m unittest discover -s .github/scripts -p test_telegram_notify.py -v
```

## Настройка реального бота

1. В Telegram найти официального [BotFather](https://t.me/BotFather), отправить `/newbot`, задать имя и username с окончанием `bot`. Открыть чат с новым ботом, нажать Start и отправить сообщение.
2. Получить числовой `chat.id` через [getUpdates](https://core.telegram.org/bots/api#getupdates). Использовать закрытый терминал с вводом токена через `getpass`, чтобы токен не остался в истории оболочки или браузера. В отчёт и чат токен не вставлять.
3. В [Actions Secrets](https://github.com/Zatik-Vustina/APRO_LR1_Zlata_Vustina/settings/secrets/actions) создать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
4. Для двух реальных пробных сообщений без запуска Unity создать Actions variable `LR6_TELEGRAM_LIVE_CHECK=true`. Повторить весь независимый прогон для `LR6`. В Telegram ожидаются два сообщения с пометкой «Проверка уведомлений ЛР №6. Unity не запускалась.». После фиксации результата переменную можно убрать.
5. После готовности игрового деплоя установить `UNITY_GAME_URL` и проверить штатное уведомление полного пайплайна при успехе и при сбое. Сохранить скриншоты доставки и ссылки на оба прогона.

Успех независимой проверки означает корректность уведомлений для заданных статусов. Полный CI/CD требует работающего тестирования Unity и опубликованной игры.
